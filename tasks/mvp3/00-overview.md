# MVP 3 — Optional Advanced Capabilities Overview

**Status:** WIP / Uncommitted  
**Goal:** Evaluate advanced capabilities only after core operations and growth automation are stable.

## Candidate scope

- Borrower-authorized financial-data ingestion from external accounting providers
- Secondary-market resale of eligible investment positions
- Advanced risk, concentration, cohort, and forecasting analytics
- Promotions/vouchers/points assessment
- Content/app communication assessment
- Legacy partner-channel assessment

## Explicitly not assumed

- A legacy feature is not approved merely because code exists for it.
- Xero/QuickBooks, secondary-market trading, multi-currency, overseas markets, partner channels, loyalty tiers, and vouchers all require separate approval.
- Legacy Singapore rules and partner-specific integrations are not Philippine launch requirements.

## Evaluation gates

- Measurable user or operating need
- Named product and operational owner
- Legal/compliance/tax assessment
- Integration and ongoing support cost
- Ledger, data, and security impact
- Clear success and retirement criteria
